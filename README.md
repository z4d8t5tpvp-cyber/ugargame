# P2P: С НУЛЯ

Браузерный симулятор P2P-трейдера с сюжетом. Артём Воронов, 20 лет, Новозаровск, 3 700 ₽ на карте Сбера и старый компьютер. Восемь глав, четыре концовки, и **ни одной кнопки «Заработать»**: каждая сделка — руками, через банк на телефоне.

## Как играть

Экран — это рабочее место Артёма:

- **Слева — компьютер (VoronovOS):** браузер с вкладками (Bybit P2P, биржа Rapira, финмодель Карима и Марата, Госуслуги/ФНС, магазин имущества), папка «Чеки и Ордера», калькулятор спреда, блокнот. Окна двигаются, сворачиваются и тормозят на старом ПК, если открыть больше трёх.
- **Справа — телефон:** СберБанк, Т-Банк, Альфа-Банк, Telegram, Барахолка, Tonkeeper, SMS и Authenticator.

**Покупка USDT.** Открываете ордер на бирже → «Скопировать номер» (номер попадает в общий буфер ПК↔телефон) → банк на телефоне → «Перевод по СБП» → «Вставить» → банк получателя → **сверяете ФИО** → переводите → «Сохранить PDF-чек» → в ордере «Прикрепить чек» → «Я оплатил».

**Продажа USDT.** Ставите своё объявление чуть дороже рынка → приходит покупатель → в банке «Обновить выписку» → проверяете **сумму и ФИО отправителя** → код из Authenticator → «Отпустить USDT». Чекам в чате и SMS с обычных номеров верить нельзя.

**Что генерируется заново в каждой игре:** курс (случайное блуждание с новостными шоками), стакан мерчантов с именами, рейтингами и лимитами, покупатели и продавцы, мошеннические сценарии (фейковый чек, перевод от третьего лица «за коляску с Авито», недоплата, реквизиты дропа, «переведи на другую карту»), покупатели на Барахолке и фишинговые ссылки «Авито Доставки», OTC-сделки с «грязными» кошельками и поддельными гарантами.

**Реализм:** бесплатный лимит СБП 100 000 ₽/мес и 1% сверх него, банковский риск по 115-ФЗ (транзит, ночные операции, нет бытовых трат, «USDT» в комментарии) → охлаждение → запрос документов → ограничение ДБО; блокировка всех карт по 161-ФЗ за принятие денег от третьего лица; комиссия мейкера, газ сетей TRC-20/TON, MEMO при депозите TON, налоги (ловушка самозанятости, ИП на УСН «Доходы минус расходы»).

Время: пауза, 1x, 2x, 5x на панели задач; во время активной сделки время замедляется. Сон — через «Пуск». Игра сохраняется в браузере автоматически.

Режимы: **Сюжетный** (меньше скама, мягче банки, ниже цели) и **Реалистичный**.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # продакшн-сборка в dist/
npm run build:offline  # один файл dist-offline/index.html — открывается двойным кликом, без сервера
```

### Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает игру на каждый push в `main` и выкладывает её на GitHub Pages; офлайн-версия кладётся рядом как `p2p-s-nulya-offline.html`. Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Устройство кода

```
src/game/            движок (без React)
  types.ts           всё состояние игры
  store.ts           zustand + immer: действия игрока, тик мира, автосохранение
  engine/            банки и 115/161-ФЗ, P2P-ордера и сценарии мошенников, рынок,
                     крипто-переводы и AML, OTC, Барахолка и подработки
  story/             главы и цели, катсцены, сценарии Telegram, режиссёр сюжета
src/ui/
  shell/             рабочий стол, окна, панель задач, телефон, полоса целей
  pc/                вкладки браузера и приложения ПК
  phone/             банки, Telegram, Барахолка, Tonkeeper, Authenticator/SMS
  cutscene/          кинематографичные сцены с выбором
```
